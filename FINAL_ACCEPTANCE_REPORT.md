## Known caveats

These do not affect the Phase 4 goal:

1. `ServerStatus.CurrentTime` is generated by asyncua's internal
   clock (written every second) rather than the simulator clock;
   subscription observers of the ServerStatus variable see the asyncua
   clock, not the simulator's per-tick timestamp.
2. The simulator writes via `iserver.write_attribute_value` so that
   `AccessLevel = 1` on the client side is preserved — clients see the
   updates but cannot themselves write to `Current` or
   `ActionSnapshot`.
3. The `ServerArray` and `ServiceLevel` values follow asyncua's
   defaults rather than the exact SUPCON export, since these are
   `ns=0` standard nodes that the rebuild server inherits from
   asyncua's default address space.
4. Phase 1 / 2 / 3 CLI tests are not yet migrated onto
   `ServerProcessHarness`; they continue to use inline `subprocess.Popen`
   invocations.  This is left for a future cleanup pass and does not
   affect acceptance.
